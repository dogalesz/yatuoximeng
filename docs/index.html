Blog & Notes

My Electronics Projects Journey

I started messing around with simple Arduino projects at 12, then paused for a while. At 13, I joined an electrical engineering course at school where I first learned analog circuits and simple microcontroller circuits with the ATmega16A. Later we moved to the STM32 for various projects using STM32CubeIDE. In winter 2024, I started coding in C, then x86 assembly. I've built countless projects and collected over 20,000 electronics components.

Which IDE is the best? (Personal opinion)

  • Arduino IDE — 3/10: good for beginners, heavy on weak machines.
  • Notepad++ — 5/10: not a proper IDE, but solid for small C/C++ files.
  • Android Studio — 6/10: heavyweight but workable. Want to improve my Kotlin first.
  • STM32CubeIDE — 7/10: best microcontroller IDE, not for beginners.
  • PyCharm — 7/10: strong Python IDE, I use it for Codeforces.
  • VSCode — 8/10: Notepad++ on steroids. Lightweight, very extensible.
  • Code::Blocks — 9.5/10: steep learning curve, cockpit vibes, but the best C/C++ IDE around.
