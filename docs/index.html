My Electronics Projects Journey

I started messing around with simple Arduino projects at 12, then I stopped for a while but at 13, I joined an electrical engineering course in my school, where I first learned analog circuits and simple microcontroller circuits with the ATmega16A. Later, we moved on to use the STM32 for various projects, which included using the STM CubeIDE. On the winter of 2024, I started coding in C, and then x86 assembly. I've made countless projects and I collected about 20000 or more electronics components.

Which IDE is the best? (Those which I've tried)

First of all, let me clarify that this is only my personal opinion and that opinions vary. You might prefer something entirely different from me.

  • Arduino IDE - 3/10: Mid, but good for beginners. This is where everyone starts. Heavy on weak machines.
  • Notepad++ - 5/10: Not a proper IDE, but its perfect for small C/C++ projects.
  • Android Studio - 6/10: Really heavyweight, but usable. I want to get better at Kotlin so that I can actually enjoy using it.
  • STM32CubeIDE - 7/10: The best microcontroller IDE, not meant for beginners.
  • PyCharm - 7/10: Strong, python focused IDE, I mostly use it for CodeForces.
  • VSCode - 8/10: Notepad++ on steroids. Lots of customization, extensions and lightweight.
  • Code::Blocks - 9.5/10: Steep learning curve, it might feel like a fighter jet cockpit at first, but REALLY good. I use it all the time. Best C/C++ IDE.
